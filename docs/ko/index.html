자주 묻는 질문

제 대화 내용을 읽나요?

아니요. 이 컴퓨터의 기록 파일에서 개수 · 토큰 수 · 시각 · 도구 이름만 세고, 대화 내용은 저장하지도 어디로 보내지도 않아요. 계산은 모두 이 컴퓨터 안에서 해요.

무료인가요?

네, 무료예요. 결제나 광고가 없어요.

Anthropic · OpenAI 가 만든 공식 앱인가요?

아니요. 개인이 만든 비공식 팬메이드 앱이에요. 두 회사와 관련이 없어요.

hook 은 뭐고, 꼭 연결해야 하나요?

Claude Code / Codex 가 일을 시작하고 끝낼 때 고양이에게 알려 주는 연결이에요. 연결하지 않아도 기록 파일로 자라지만, 연결하면 작업 끝 · 허락 요청에 바로 반응해요. 기존 설정은 그대로 두고 백업도 만들어요.

방해되지 않나요?

고양이는 화면 맨 아래를 걸어 다니고, 클릭은 고양이 몸 위에서만 받아요. 크기 조절, 음소거, 한 시간 숨기기, 방해 금지 모드가 있어요.

맥은 왜 경고가 뜨나요?

Apple 개발자 서명(유료)이 없는 베타라서, 처음 한 번만 설정에서 열어 줘야 해요. 그다음부터는 그냥 열려요.
