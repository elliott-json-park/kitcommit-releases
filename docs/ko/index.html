토큰을 먹고 자라요

보낸 메시지와 출력 토큰만큼 경험치가 쌓여 레벨이 오르고, 코인으로 옷·모션·간식을 사요.

같이 일하고 알려 줘요

답을 만드는 동안 노트북으로 같이 타이핑하고, 허락이 필요하면 손을 흔들고, 오래 걸린 답이 끝나면 말풍선으로 알려 줘요. 짧은 답엔 폴짝 뛰기만 해요.

생활을 챙겨 줘요

점심·저녁 시간, 두 시간째 일할 때의 스트레칭, 늦은 밤 작업할 때 건네는 위로의 말까지. 고양이가 내 생활을 챙겨 줘요.

이제 고양이와 대화해요

내가 쓰는 AI를 연결하면 고양이가 진짜로 대답해요. 수다 · 고민 상담 · 간단한 질문에 같이 하는 말놀이까지. 일 비서가 아니라 친구예요.

  • 🎭

    성격 7가지

    다정한 · 츤데레 · 장난꾸러기 · 시크한 · 수다쟁이 · 애늙은이 철학자 · 귀차니스트. 직접 설명을 더할 수 있고, 말풍선도 같은 성격으로 말해요.

  • 📝

    기억하고 챙겨 줘요

    기억 노트에 내 얘기를 적어 두고, "30분 뒤에 양치하라고 알려줘" 하면 진짜로 알려 줘요. 집중 시간 타이머도 있어요.

  • ⌨️

    언제든 불러요

    Ctrl+Alt+K (맥은 ⌘+Option+K), 트레이, 고양이에 마우스를 올리면 뜨는 "말 걸기"로 열어요.

자주 묻는 질문

제 대화 내용을 읽나요?

아니요. Claude Code · Codex 는 이 컴퓨터의 기록 파일에서 개수 · 토큰 수 · 시각 · 도구 이름만 세고, 브라우저 확장은 보냈다 · 답이 끝났다 · 글자 수 · 시각만 앱에 알려요. 대화 내용은 저장하지도 어디로 보내지도 않아요.

고양이와 대화하려면 돈이 드나요?

Claude · ChatGPT 구독이 있으면 따로 낼 돈 없이 그 구독으로 대화해요 (구독 사용량을 조금 써요). 구독이 없으면 Gemini 무료 키로 시작할 수 있어요. 오늘의 냥운세는 AI 없이도 돼요. 고양이와 나눈 대화는 이 컴퓨터에 저장되고, 내가 연결한 AI 로만 가요.

Claude Code 나 Codex 없이 브라우저에서만 써도 되나요?

네. 처음 안내에서 "브라우저"를 고르고 작은 확장(크롬 · 엣지 · 웨일)을 넣으면 claude.ai · chatgpt.com · gemini.google.com 을 쓸 때 고양이가 자라요. 설치는 앱이 한 단계씩 안내해요.

무료인가요?

네, 무료예요. 결제나 광고가 없어요.

Anthropic · OpenAI · Google 이 만든 공식 앱인가요?

아니요. 개인이 만든 비공식 팬메이드 앱이에요. 세 회사와 관련이 없어요.

hook 은 뭐고, 꼭 연결해야 하나요?

Claude Code / Codex 가 일을 시작하고 끝낼 때 고양이에게 알려 주는 연결이에요. 연결하지 않아도 기록 파일로 자라지만, 연결하면 작업 끝 · 허락 요청에 바로 반응해요. 기존 설정은 그대로 두고 백업도 만들어요.

방해되지 않나요?

고양이는 화면 맨 아래를 걸어 다니고, 클릭은 고양이 몸 위에서만 받아요. 말풍선은 꼭 필요할 때만 띄우고, 크기 조절 · 음소거 · 한 시간 숨기기 · 방해 금지 모드가 있어요.

맥은 왜 경고가 뜨나요?

Apple 개발자 서명(유료)이 없는 베타라서, 처음 한 번만 설정에서 열어 줘야 해요. 그다음부터는 그냥 열려요.
